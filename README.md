# TestyStuff

Browser-only Step Sequencer (Vanilla JS, Web Audio API, localStorage).

This is a scaffold stub. Full documentation lands in a later story.

## Development

- `npm install` — install dev dependencies (Vitest + JSDOM).
- `npm test` — run the test suite once.
- `npm run test:watch` — Vitest watch mode.
- `npm run serve` — serve the static app on `http://localhost:8080`.
